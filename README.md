# Portfolio — Vivek Kumar Singh

A personal portfolio website showcasing my skills, experience, and projects as an **ML Engineer** specializing in search, ranking, and marketplace ML systems.

## Live Preview

Visit the portfolio by opening `index.html` in any modern browser, or deploy it via GitHub Pages.

## Features

- **Responsive Design** — Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI** — Glassmorphism effects, gradient accents, smooth animations, and a clean cream-toned aesthetic
- **Interactive Elements** — Scroll-triggered animations, parallax blobs, hover effects on cards and buttons
- **Sections Included:**
  - Hero section with a brief introduction and social links
  - About Me
  - Skills & Technologies
  - Projects showcase
  - Contact information

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Flexbox/Grid layouts, keyframe animations, backdrop-filter effects
- **JavaScript** — Scroll interactions and UI logic
- **Google Fonts** — Playfair Display, Sora, Space Mono

## Getting Started

```bash
# Clone the repository
git clone https://github.com/VivekRahal/porfolio.git

# Open in browser
open index.html
```

## Deployment

This is a static site and can be deployed on:
- **GitHub Pages** — Enable in repo settings under Pages
- **Netlify / Vercel** — Drag and drop the folder or connect the repo
